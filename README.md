## 🧠 What is VYRA?

Modern users don't have an information problem.

They have an **attention problem**.

Messages arrive continuously. Some are urgent. Some are important. Some can wait. Some require action. Others are noise.

**VYRA** is an **Attention Operating System** designed to intelligently triage this information.

Instead of simply summarizing your inbox, VYRA creates an explainable decision layer:

> **What matters now?**  
> **What can wait?**  
> **What needs action?**  
> **Why does it matter?**  
> **What should I do next?**
